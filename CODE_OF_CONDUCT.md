# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique ideas rather than people, and keep discussion on topic. Harassment, personal attacks, and publishing others' private information are not tolerated.

## Reporting

Report conduct concerns privately to the maintainer through their GitHub profile ([bsommers](https://github.com/bsommers)), or through GitHub's **Report content** option on the offending comment or issue. Reports are handled confidentially. The maintainer may remove content, or block contributors, that violate this code.
