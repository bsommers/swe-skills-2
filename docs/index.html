Quickstart & Operational Recipes

1. Multi-Harness Install & Profiles

Install all 69 skills across Claude Code, Antigravity, and Cursor, or mount a focused profile to save ~85% prompt tokens.

scripts/install.sh --all scripts/install.sh --claude --profile core python3 scripts/hooks/install-hooks.py --claude --agy
2. /eng Unified Router & Shortcuts

Type /eng with free text to size & route automatically, or invoke an exact shortcut word.

/eng add retry logic across API modules /eng tdd # designing-exhaustive-test-cases /eng qa-drive # driving-browsers-for-qa /eng chain # 5-step lossless session chain
3. Render SVG/PNG Graphics & Verify Suite

Re-render all 13 SVG + 13 PNG neon-grid visuals, rebuild GitHub Pages, and run the verification suite.

python3 scripts/render-graphics.py python3 scripts/build-pages.py python3 scripts/lint-skills.py --words python3 -m unittest discover tests -q
